# Session — 2026-04-02

## RAR extraction + MakeMKV (qwerty)

Extracted CODA (2021) Blu-ray from a multi-part RAR archive and converted to MKV for Jellyfin.

### Steps
- Downloaded torrent arrived as `.rar` + `.r00`–`.r73` split archive
- Installed `unrar` on qwerty (Ubuntu 22.04) via multiverse repo:
  ```
  sudo add-apt-repository multiverse && sudo apt update && sudo apt install unrar
  ```
- Extracted with: `unrar x <file.rar> <output-dir>/`
- Result was a `CODA.ISO` Blu-ray disc image
- Installed MakeMKV via PPA (`ppa:heyarje/makemkv-beta`) and ran:
  ```
  sudo makemkvcon mkv iso:/path/to/CODA.ISO all /output/dir/
  ```
- MakeMKV produced 7 titles — `t00` is always the main feature (longest, from the `.mpls` playlist)
- Deleted `t01`–`t06` (bonus content): `sudo rm /path/CODA_t0[1-9]*`

### Key findings
- `unrar-free` (default Ubuntu package) fails on modern RAR archives — always use `unrar` from multiverse
- MakeMKV with `sudo` needed because Jellyfin media dirs are owned by the jellyfin service user
- Files landed in `/mnt/storage/jellyfin/movies/Coda (2021)/`

## Homelab organisation planning (this session)

Decided on a structure for tracking homelab state and documentation from the NixOS machine.

### Decisions
- Config tracking: bare git repo per machine (`~/.homelab-configs/`, `--work-tree=/`)
  mirrors the dotfiles pattern — tracks `/etc/` files without `.git` inside `/etc/`
- Config repos cloned to `Raymer/<machine>/` on NixOS as read-only snapshots
- Official docs live in `Raymer/docs/` (current deployed state, runbooks)
- Zettelkasten `Inside/Projects/Homelab/` stays as a learning resource only — experiments,
  MOC mini-projects, failed builds — not treated as authoritative state by agents
