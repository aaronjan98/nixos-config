# Session — 2026-04-02

## What was worked on
- Researched and installed LFM2-24B-A2B and LFM2-8B-A1B (Liquid AI) locally using llmfit + llama-server
- Benchmarked both models with llama-bench to find optimal thread count
- Investigated tool calling support and Claude Code harness compatibility

## Key insights
- LFM2-24B-A2B Q4_K_M is 13.4 GB — fits in 30 GB RAM but requires Ollama stopped first to have headroom
- LFM2-8B-A1B Q4_K_M is only 4.7 GB and outperforms the 24B on this hardware due to lower memory bandwidth demand
- On Ryzen 7 PRO 5850U (integrated Vega, CPU-only): 8 threads is the sweet spot — more threads saturate memory bandwidth and hurt performance
- llmfit `search` returns mlx/non-GGUF results; use `hf-search` to find actual GGUF repos on HuggingFace
- Official LiquidAI GGUF repos exist (`LiquidAI/LFM2-8B-A1B-GGUF`, `LiquidAI/LFM2-24B-A2B-GGUF`) — prefer these over community quantizers when available; use bartowski only if you need IQ-series quants not published by the author
- LFM2-8B-A1B supports tool calling via special tokens in its chat template

## Benchmark results (Ryzen 7 PRO 5850U, 8 threads, CPU-only)

| model | quant | size | pp512 | tg128 |
|---|---|---|---|---|
| LFM2-24B-A2B | Q4_K_M | 13.42 GiB | 9.55 tok/s | 5.41 tok/s |
| LFM2-8B-A1B | Q4_K_M | 4.70 GiB | 12.61 tok/s | 6.75 tok/s |

## Decisions
- LFM2-8B-A1B Q4_K_M chosen as the practical model for this hardware
- Run llama-server with `-t 8 -c 4096 --host 127.0.0.1 --port 8080`
- llama-bench confirmed already installed as part of `llama-cpp` nixpkgs package — no config change needed
