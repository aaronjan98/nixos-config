# MEMORY.md

## Purpose
This file explains how memory works for the research paper project.

## Operational memory
Daily or session-specific notes belong in:

- `memory/YYYY-MM-DD.md`

Use these notes for:
- what was worked on today
- blockers
- next steps
- source discoveries
- questions that are still open

## Durable project memory
Stable project knowledge belongs in:

- `project-memory/`

Use this for:
- settled thesis wording
- accepted terminology
- stable paper structure
- citation/style decisions
- durable findings that should not depend on chat history

## Rules
- Do not leave important paper decisions only in chat.
- Do not put transient daily notes into durable memory.
- Use daily notes for work-in-progress thinking.
- Use project-memory for stable decisions and durable paper truths.
