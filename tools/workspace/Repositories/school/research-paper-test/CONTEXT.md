# CONTEXT.md

## Project
research-paper

## Purpose
This repository is for developing a class research paper with AI support.
The agent should help with brainstorming, source synthesis, argument mapping, paragraph critique, and revision support.
Final editing and polishing will happen in LibreOffice, not directly in this repository.

## What good looks like
- A clear and defensible thesis
- Good source synthesis rather than disconnected summaries
- A workable paper structure with strong section logic
- Useful agent assistance without losing human control over writing

## What to avoid
- Overwriting the paper's voice with generic AI prose
- Treating weak exploratory notes as settled conclusions
- Searching unrelated repositories by default
- Relying on chat history instead of writing down durable decisions

## Main directories
- `notes/` — planning notes, research question, and working thesis
- `sources/` — source notes, excerpts, and reading materials related to the paper
- `analysis/` — synthesis, comparisons, themes, and argument structure
- `drafts/` — markdown section drafts or excerpts for feedback
- `memory/` — daily operational notes
- `project-memory/` — durable project knowledge

## Working rules
- Start with the files most directly related to the current paper task.
- Use the repository itself by default.
- Consult declared dependencies only when relevant.
- Prefer helping with structure, clarity, and synthesis over writing generic filler text.
- Keep project decisions written down rather than leaving them only in chat.

## Workflow
1. Clarify the current paper task.
2. Inspect the most relevant notes, source files, or draft sections.
3. Produce the smallest useful output: critique, synthesis, outline adjustment, or draft suggestion.
4. Record important next steps or decisions in the appropriate project files.
