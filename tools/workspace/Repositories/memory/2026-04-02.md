## Decisions made
- `agents/claude/` is the authored source of truth for Claude-specific config; `~/.claude/` is runtime only
- Memory belongs in project-local files, not `~/.claude/projects/`
- Tool command preferences go in `~/.config/ai/shared/tool-commands.md` (agent-agnostic)
- Agent "personalities" are implemented via CONTEXT.md + spawn location, not separate profile mechanisms
- Automated AI sweeps of the vault are the wrong tool; use deliberate vault-review sessions instead
- Index files should be annotated (one-line sub-bullets per link) with an "Historical" section at the bottom
