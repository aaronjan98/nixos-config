## Key Insights

### SSH hang root cause
- Script uses `ssh -o BatchMode=yes sauron` which resolves via `~/.ssh/config` to `ssh.aaronjanovitch.com:2221`
- Public IP changed recently; DDNS now points to `104.173.16.68` (was `23.241.163.161`)
- Local `~/.ssh/known_hosts` had sauron's host key stored under the old IP `[23.241.163.161]:2221` but NOT under `[ssh.aaronjanovitch.com]:2221`
- BatchMode disables interactive prompts, so SSH silently fails host key verification → infinite wait loop
- **Fix:** `ssh-keyscan -p 2221 ssh.aaronjanovitch.com >> ~/.ssh/known_hosts` on the local machine

### Ollama at 100% CPU
- `summarizer-api.service` (uvicorn/FastAPI on port 8008) is the video summarization backend
- It holds an in-flight job queue; when `ollama.service` restarts, the API resubmits pending jobs
- Restarting only ollama does NOT clear the queue — the API keeps resubmitting
- **Fix:** Stop summarizer-api first, then ollama:
  ```bash
  sudo systemctl stop summarizer-api.service && sudo systemctl stop ollama.service
  ```
  Then restart when ready:
  ```bash
  sudo systemctl start ollama.service summarizer-api.service
  ```
- Killing runners in htop works as a last resort but is not the clean approach

---

## Decisions
- DDNS hostname `ssh.aaronjanovitch.com` is the canonical external address for sauron (ports 2221 for SSH, 2222 for other hosts)
- `summarizer-api.service` must always be stopped before ollama to avoid queue resubmission
