## 17:22 PDT — NixOS generation cleanup and maintenance docs

### What was worked on
- clarified why `nix-collect-garbage` did not remove old NixOS boot generations on its own
- explained the `Specialisation` column in `nixos-rebuild list-generations`
- added `boot.loader.systemd-boot.configurationLimit = 10;` to keep future boot entries capped
- documented helpful NixOS maintenance commands in a new `docs/NIXOS-MAINTENANCE.md`

### Key insights
- `nix-collect-garbage` handles store cleanup, not system-generation deletion by itself
- deleting old **system** generations uses `nix-env --profile /nix/var/nix/profiles/system --delete-generations old`
- `nixos-rebuild list-generations` is the easiest way to inspect current and old system generations
- `Specialisation = []` means the normal base configuration with no specialisation active

### Decisions
- keep garbage collection manual for now
- document generation cleanup and related commands in the repo docs rather than only in chat

### Next steps
- optionally enable automatic Nix garbage collection later if manual cleanup becomes annoying
