## Key insights
- `~/.ssh/config` is not Nix-managed — it lives in `pass` at `laptop/<hostname>/ssh/config` and is written to disk by `restore-secrets.sh`
- The pass prefix is hostname-derived using `$(hostname)`, so each machine has its own SSH entries in the store
