# Session Notes — 2026-04-10

## Topic: CVE-2026-39860 — Nix privilege escalation via symlink following

### Vulnerability summary
- **CVE-2026-39860** (GHSA-g3g9-5vj6-r3gj): Nix daemon follows symlinks unsafely during fixed-output derivation (FOD) output registration, allowing any user who can submit builds to overwrite arbitrary files as root.
- Affects all NixOS multi-user setups with Linux sandbox enabled (standard config).
- Exploitation: craft a malicious FOD output containing a symlink to a sensitive file; the daemon (root) follows it and writes there.
